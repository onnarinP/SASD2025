# ตัวอย่าง C# Class จาก .NET API (.NET 10)

# a) Utility Class

## ตัวอย่าง: System.Math

`System.Math` เป็นคลาสใน namespace `System` ที่ให้เมทอดสำหรับการคำนวณทางคณิตศาสตร์ เช่น

- Math.Abs()
- Math.Sqrt()
- Math.Pow()
- Math.Round()
- Math.Max()
- Math.Min()

### ตัวอย่างการใช้งาน

```csharp
double x = -10.5;
double absValue = Math.Abs(x);
double squareRoot = Math.Sqrt(25);
double power = Math.Pow(2, 3);
```
วิเคราะห์ว่าเหตุใดจึงเป็น Utility Class
- มีแต่ static members
- คลาส Math ไม่สามารถสร้าง instance ได้ (constructor เป็น private)
- ทุกเมทอดเป็น static
- ไม่มี state (Stateless)
- ไม่มี field ที่เก็บค่าภายใน object
- ไม่มีข้อมูลที่เปลี่ยนแปลงตาม instance
- ทำหน้าที่คำนวณแล้วคืนค่าเท่านั้น
- เป็นคลาสเครื่องมือ (Tool Class)
- ใช้ช่วยงานทั่วไป
- ไม่แทน entity หรือ object ใด ๆ

# b) Mutable Class
## ตัวอย่าง: System.Text.StringBuilder
`System.Text.StringBuilder` เป็นคลาสสำหรับจัดการข้อความที่สามารถแก้ไขได้โดยไม่ต้องสร้าง object ใหม่ทุกครั้ง  

### ตัวอย่างการใช้งาน
```csharp
using System.Text;
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World");
sb.Replace("World", "C#");
Console.WriteLine(sb.ToString());
```
วิเคราะห์ว่าเหตุใดจึงเป็น Mutable Class
- มี internal state
- StringBuilder มี buffer ภายในที่เก็บข้อมูลตัวอักษร
- เปลี่ยนแปลงสถานะเดิมได้
- เมทอดอย่าง Append(), Insert(), Remove(), Replace()
- จะทำการแก้ไข object เดิม
- ค่าภายใน sb เปลี่ยนไปทันที
- ไม่คืน object ใหม่ทุกครั้ง
- ต่างจาก string ที่ immutable
- StringBuilder ทำงานบน instance เดิม
 
ตัวอย่าง:  
```csharp
sb.Append("!!!");
```
# c) Immutable Class
ตัวอย่าง: System.String

`System.String` เป็นคลาสแทนข้อความใน C#  

### ตัวอย่างการใช้งาน  
```csharp
string text = "Hello";
text = text + " World";
Console.WriteLine(text);
```
วิเคราะห์ว่าเหตุใดจึงเป็น Immutable Class  

- เปลี่ยนค่าไม่ได้หลังสร้าง
- เมื่อสร้าง string แล้ว ค่าภายในไม่สามารถเปลี่ยนได้

### ตัวอย่าง:
```csharp
string s = "Hello";
s.Replace("H", "J");
```

- บรรทัดนี้ไม่ได้แก้ s เดิม แต่จะคืนค่า string ใหม่
- ทุกการแก้ไขจะสร้าง object ใหม่
  
```csharp
string newText = text.Replace("Hello", "Hi");
```

- newText เป็น object ใหม่
- text เดิมไม่เปลี่ยน
- ปลอดภัยต่อ Multithreading เพราะไม่มีการเปลี่ยน state ภายใน
- หลาย thread ใช้ string เดียวกันได้อย่างปลอดภัย
- มีการออกแบบเพื่อ performance (String Interning) .NET ใช้กลไก intern pool เพื่อ reuse string เดิม

## สรุป
### Utility Class: 
- รวมเมทอดที่เกี่ยวข้องกัน
- ไม่มี instance state
- มักเป็น static ทั้งหมด
### Mutable Class  
- เปลี่ยนแปลงข้อมูลได้
- เหมาะกับงานที่ต้องแก้ไขข้อมูลบ่อย
- ต้องระวังเรื่อง concurrency
### Immutable Class  
- ไม่เปลี่ยนแปลงหลังสร้าง
- ปลอดภัยกับ multithreading
- เหมาะกับ value object และ functional style
